# Bhargav Sai K — Portfolio

A responsive portfolio built with Vite, vanilla JavaScript, and GSAP ScrollTrigger. Includes personal projects, experience, skills, contact links, and the supplied downloadable resume.

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

`dist/` contains the complete static site and can be deployed to any static host. The Sites manifest is in `.openai/hosting.json`.

## Editing

- `src/index.html`: content, navigation, project and contact links
- `src/style.css`: theme, layouts, and responsive breakpoints
- `src/main.js`: GSAP motion; respects reduced-motion settings
- `public/professional.png`: supplied portrait
- `public/Bhargav_Sai_Resume.pdf`: supplied resume, unchanged

Project repository URLs were extracted from the resume. The website uses the contact email and employment details supplied in the request, which supersede the older resume content. Project visuals are stylized interface illustrations, not screenshots of the deployed applications.
